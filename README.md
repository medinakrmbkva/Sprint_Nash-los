#  Нашлось! — Бюро находок студентов

Учебный frontend-прототип для студентов. Здесь можно потерять или найти вещь, сдать/взять учебники в аренду, обменять конспекты или просто помочь друг другу. 

Проект написан на «чистом» HTML, CSS и JavaScript без использования сторонних библиотек и сборщиков.

##  Что умеет проект (Функционал)

* **Категории:** 5 разделов — Потерял, Нашёл, Аренда, Обмен и Помощь.
* **Поиск и фильтры:** поиск по названию/описанию, фильтрация по месту (Библиотека, Столовая и т.д.) и категории.
* **Сортировка:** «Сначала новые» и «Сначала дешевле».
* **Создание объявлений:** валидация полей и **загрузка фотографий** (изображение конвертируется в Base64 и сохраняется в браузере).
* **Избранное (♡):** можно сохранять понравившиеся объявления, счётчик отображается в шапке.
* **Профиль:** выпадающее меню с доступом к избранному и информации о профиле.
* **Детальный просмотр:** модальное окно с полной информацией и кнопкой копирования контакта автора.
* **Сохранение данных:** все объявления и избранное остаются в браузере после перезагрузки страницы (LocalStorage).
* **Адаптивность:** интерфейс подстраивается под телефоны, планшеты и ноутбуки.

##  Особенности дизайна

* Стильная тёмная тема с неоновыми акцентами (фиолетовый, бирюзовый, лаймовый).
* Плавные анимации при наведении, всплывающие уведомления (тосты).
* Модальные окна закрываются по клику на фон или клавише `Esc`.

##  Технологии

* **HTML5** — семантическая разметка.
* **CSS3** — CSS-переменные, Grid, Flexbox, медиазапросы, `backdrop-filter`.
* **Vanilla JavaScript (ES6+)** — работа с DOM, события, LocalStorage, FileReader API, манипуляции с массивами.
